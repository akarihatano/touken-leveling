📖このアプリについて
概要
資源帳は、刀剣乱舞の木炭・玉鋼・冷却材・砥石などの資源を日々記録し、推移をグラフで確認できる管理ツールです。
ゲーム内のデータを自動取得することはありません。すべて審神者本人の手入力によって記録していくツールです。
💾 データの保存
データはお使いの端末のブラウザ内（ローカルストレージ）にのみ保存されます。
管理人がデータを確認・アクセスすることは一切ありません。
Google ドライブ同期はバックアップの一つとしてご利用ください。
※「期間・日別メモのデータ」と「資源グラフのデータ」は別の場所でそれぞれインポート・エクスポートします。
🔄 稽古録との互換性
「期間・日別メモのデータ」は資源帳・稽古録で共通して使えます。
一方のアプリでエクスポートしたデータを、もう一方にインポートすることが可能です。
🌐 推奨ブラウザ
  • PC：Chrome / Edge / Firefox
  • スマートフォン：Chrome / Firefox / Safari
⚠ アプリ内ブラウザ（WebView）をお使いの方へ
SNS アプリなどのアプリ内ブラウザでは、Google ドライブとの同期が動作しません。
（Google のセキュリティポリシーによる制限です）
同期を使う場合は推奨ブラウザからアクセスしてください。
同期の代わりに「データ一覧」タブのインポート・エクスポートもご活用ください。
📊グラフタブ
入力した資源の推移を折れ線グラフで確認できます。複数の資源を同時に表示し、傾向を一目で把握できます。
表示期間の切り替え
  • 全期間：記録したすべてのデータを表示します
  • 1ヶ月 / 3ヶ月：最新の記録から遡って表示します
  • カスタム：開始日・終了日を自由に指定できます
増減差分・上限線
  • 増減差分ボタン：前回記録との差分（増減量）を表示します
  • 上限線ボタン：木炭・玉鋼・冷却材・砥石の上限（9,999,999）、依頼札・手伝い札の上限（99,999）を点線で表示します
凡例（資源の表示 / 非表示）
グラフ上部の凡例（色付きの名前）をタップすると、その資源のグラフ線を個別に表示・非表示にできます。
お札グラフ
メインのグラフとは桁が大きく異なるため、お札（富士・松・竹・梅）は専用のグラフとしてメイングラフの下に表示されます。
  • グラフ右上の「お札 on/off」ボタンで、お札グラフの表示・非表示を切り替えられます
  • お札グラフの凡例をタップすると、種類ごとに線を表示・非表示にできます
設定タブの「お札グラフ」からも表示・非表示を変更できます。
期間メモの表示スタイル
グラフ上に期間メモを重ねて表示できます。表示スタイルは3種類から選べます。
  • 帯：期間を半透明の帯で塗りつぶします（デフォルト）
  • ガントバー：グラフ下にバー形式で表示します
  • ブラケット：期間の両端に括弧形式で表示します
期間メモ名をタップするとハイライト表示できます。「すべて選択」「すべて解除」ボタンで一括操作も可能です。
x 軸の日付形式
グラフ下の x 軸エリアをタップすると、日付の表示形式を切り替えられます。
  • ① 年-月-日（常にフル表示）
  • ② 年切替時のみ年を表示（デフォルト）
  • ③ 年 → 月 → 日（省略形式）
設定タブからも変更できます。
✏️資源入力タブ
その日の資源量を記録します。ゲームの資源画面を見ながら入力してください。
日付の選択
📅 日付欄をタップするとカレンダーが開き、記録したい日を選べます。◀ ▶ で月を切り替えられます。
今日ボタンで本日の日付に切り替え、←・→ で前後の日に移動できます。
同じ日付のデータがすでにある場合は上書きされます。

連隊戦などで手に入るお札も、上記の資源とは別グループとして同じ日付にまとめて記録できます。グラフでは専用の「お札グラフ」に表示されます。

引き継ぎ・クリア
選択中の日付より前の直近の記録から、数値をワンタップでコピーできます。前回から変動の少ない資源を入力する手間を省けます。
  • ↩ 札を引き継ぐ：富士・松・竹・梅の4種類だけを引き継ぎます
  • ↩ 全資源を引き継ぐ：すべての資源とお札を引き継ぎます
  • ✕ クリア：入力中の数値をすべて空にします
引き継ぎ後の数値は手動で修正できます。過去の記録が1件もない場合、引き継ぎボタンは押せません。
💡 お札だけ引き継げる理由
お札は資源と比べて増減のタイミングが限られるため、前回の枚数をそのまま引き継いで、変わった分だけ直す使い方が便利です。
📅期間・日別メモタブ
グラフ上にイベントや日々のメモをオーバーレイ表示するための機能です。
期間メモ
連隊戦やキャンペーン期間など、複数日にわたる期間をグラフ上に表示できます。
  • プリセットから選択すると名前が自動入力されます（手動修正も可能）
  • 開始日・終了日は📅 ボタンをタップしてカレンダーから選びます
  • 表示色を設定して「追加する」を押します
  • 追加したメモはグラフ上に帯・ガントバー・ブラケットのいずれかで表示されます
日別メモ
特定の日付に一言メモを残せます。日付は📅 ボタンからカレンダーで選択します。グラフ上で縦線と連動して表示され、タップすると内容を確認できます。
💡 使い方の例
「修行から帰還」「刀帳コンプ達成」「〇〇を入手」など、資源の変化と合わせて覚えておきたい出来事を記録しておくと便利です。
エクスポート / インポート
「期間・日別メモ エクスポート」でデータを JSON ファイルとして保存できます。
「期間・日別メモ インポート」で JSON ファイルを読み込めます。
このデータは稽古録とも共通です。稽古録でエクスポートしたデータをそのまま資源帳にインポートすることができます。
⛵遠征タイマー
遠征の残り時間をカウントダウンするタイマーです。複数の遠征を同時に管理できます。
遠征の開始方法
  • プリセットからよく使う遠征を選ぶと、名前と時間が自動入力されます（1-1 〜 5-4 に対応）
  • プリセットにない遠征は遠征名・時間（時・分・秒）を手動で入力してください
  • 入力したら「出発」ボタンを押すとカウントダウンが始まります
早め通知
「早め通知」にチェックを入れると、終了の10〜60秒前にも通知します。 うっかり見逃しを防ぎたい場合にご活用ください。
タイマー一覧の並び替え
  • 残り時間順：もうすぐ終わる遠征を上に表示します
  • 名前順：遠征名のあいうえお順で表示します
💡 通知について
設定タブ → 「通知の許可」からブラウザへの通知許可を付与しておくと、タブが非アクティブでも音と通知バナーでお知らせします。
まず「テスト通知を送る」で動作確認してみてください。
🔧手入れタイマー
刀剣男士の手入れ時間をカウントダウンするタイマーです。複数同時管理に対応しています。
  • 刀の名前を入力しておくと、完了時にどの刀の手入れが終わったか一目でわかります（省略可）
  • 時間（時・分・秒）を入力して「手入れ」ボタンを押します
  • 早め通知・並び替えも遠征タイマーと同様に使えます
⚒️鍛刀タイマー
鍛刀の完成時間をカウントダウンするタイマーです。複数の鍛刀を同時に管理できます。
  • 時間（時・分・秒）を入力して「鍛刀」ボタンを押します
  • 早め通知・並び替えも遠征・手入れタイマーと同様に使えます
📋データ一覧タブ
記録したすべての資源データを一覧表示します。各行の編集・削除も行えます。
エクスポート（書き出し）
  • JSON 書き出し：アプリ専用のバックアップ形式。インポートに完全対応
  • CSV 書き出し：Excel などの表計算ソフトで開ける形式
インポート（読み込み）
  • JSON 読み込み：このアプリからエクスポートした JSON を復元します
  • CSV 読み込み：CSV ファイルから資源データを読み込みます
  • Excel 読み込み：これまで Excel で記録していたデータを取り込めます（.xlsx / .xls）
⚠ Excel 読み込みの形式について
1行目はヘッダー行（日付列は「日付」「date」または空欄で自動検出）
列名：木炭 / 玉鋼 / 冷却材（冷却水でも可）/ 砥石 / 小判 / 依頼札 / 手伝い札
日付フォーマット：2025/11/12 または 2025-11-12
※必ず読み込めるわけではありません。文字列列はメモとして自動取り込みされます。
⚙️設定タブ
カラーテーマ
  • 夜刀：青みがかった暗い配色
  • 暁光：暖色系の落ち着いた配色
  • 翠嵐：緑系の涼しげな配色
  • 白磁：モノクロ系のシンプルな配色（デフォルト）
お札グラフ
グラフタブにお札（富士・松・竹・梅）の在庫推移グラフを表示 / 非表示で切り替えます。お札を記録していない場合は非表示にしておくとすっきりします。
明暗モード
  • テーマに従う：各テーマのデフォルト設定に従います
  • ダーク / ライト：強制的に明暗を固定します
  • システム：端末の設定（ダーク / ライトモード）に自動で合わせます
レイアウト
  • 自動：画面幅 600px 未満でスマートフォン向けレイアウトに切り替わります（デフォルト）
  • PC / スマホ：強制的にレイアウトを固定できます
ヘッダー右上のアイコンからもレイアウトを切り替えられます。
通知の許可
「許可を求める」ボタンからブラウザへの通知許可を設定できます。
許可後は「テスト通知を送る」で動作確認ができます。
通知はページ内のバナーと効果音でもお知らせします。
クラウド同期（Google Drive）
Google アカウントでログインすると、データを Google ドライブへ保存・読み込みできます。
ヘッダーの 「↑ 保存」「↓ 読み込み」 ボタンから手動で同期します。
一度ログインすると、ページを再読み込みしてもログイン状態が維持されます（タブを閉じるまで有効）。毎回ログインし直す必要はありません。
「クラウドが新しい場合に警告を表示する」のチェックを入れておくと、クラウドのデータの方が新しいときに上書き確認ダイアログが表示されます。
⚠ SNS アプリ内ブラウザでは同期できません
X（Twitter）・LINE などのアプリ内ブラウザでは Google のセキュリティポリシーにより同期が機能しません。
Chrome・Safari など外部ブラウザでご利用ください。
データのリセット
「リセット」ボタンを押すと、すべての資源データと記録が削除されます。
⚠ 操作は取り消せません
リセットする前に必ずデータ一覧タブからエクスポートしてバックアップを取ってください。
🔒バックアップについて
ブラウザのキャッシュ削除・機種変更・ブラウザ変更を行うとデータが消える場合があります。
定期的なバックアップを強くおすすめします。
資源データのバックアップ
  • 「データ一覧」タブ → 「JSON 書き出し」 でファイルとして保存
  • ヘッダーの 「↑ 保存」 ボタンで Google ドライブへ同期
期間・日別メモのバックアップ
  • 「期間・日別メモ」タブ → 「期間・日別メモ エクスポート」 でファイルとして保存
⚠ 注意：2 つのデータは別々に保存が必要です
「資源データ」と「期間・日別メモ」は保存場所が異なります。
Google ドライブ同期でバックアップできるのは資源データのみです。
期間・日別メモは別途エクスポートして保存してください。
❓よくある質問
Q. データが消えてしまった
ブラウザのキャッシュ・サイトデータを削除するとデータが消えます。
JSON エクスポートまたは Google ドライブ同期でバックアップを取っておいてください。
Q. スマートフォンで文字が小さい・使いにくい
設定タブ → レイアウト → 「スマホ」 に切り替えると、モバイル向けの表示になります。
ヘッダー右上のレイアウトボタンからもすぐに切り替えられます。
Q. 通知が届かない
設定タブ → 「通知の許可」からブラウザへの通知許可をオンにしてください。
端末のブラウザ設定で通知がブロックされている場合は、端末の設定からも許可が必要です。
また、SNS アプリなどのアプリ内ブラウザでは通知が機能しない場合があります。
Q. Google ドライブにログインできない
X（Twitter）・LINE などのアプリ内ブラウザでは、Google のセキュリティポリシーにより動作しません。
Chrome・Safari・Firefox などの外部ブラウザでアクセスしてください。
Q. 複数の端末で同じデータを使いたい
Google ドライブ同期をご利用ください。各端末でログインし、手動で保存・読み込みすることでデータを共有できます。
新しい端末では先に 「↓ 読み込み」 ボタンでクラウドのデータを取得してください。
Q. グラフに何も表示されない
「資源入力」タブでデータを追加してください。
データが 1 件以上ないとグラフは表示されません。
また、表示期間の設定（1ヶ月・3ヶ月）がデータの記録日より新しい場合も表示されません。その場合は「全期間」に切り替えてご確認ください。
