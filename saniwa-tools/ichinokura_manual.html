📖このアプリについて
概要
愛蔵の一ノ倉は、刀剣乱舞の宝物・断片・刀装・馬を管理するツールです。
手に入れた宝物を個体ごとに記録し、レベル・愛用度・刻名を残したり、ステータスで並べ替えて装備の検討に使えます。
ゲーム内のデータを自動取得することはありません。すべて審神者本人の手入力によって記録していくツールです。
📑 5つのタブ
  • 断片管理：断片の所持数を記録し、宝物の製作計画を立てる
  • 宝物帳：所持している宝物を個体ごとに管理する
  • 刀装：刀装のステータス一覧を閲覧・並べ替える
  • 馬：馬のステータス一覧を閲覧・並べ替える
  • 暦メモ：イベント期間や日々のメモをカレンダーに記録する
💾 データの保存
データはお使いの端末のブラウザ内（ローカルストレージ）にのみ保存されます。
管理人がデータを確認・アクセスすることは一切ありません。
Google ドライブ同期・JSON エクスポートはバックアップの一つとしてご利用ください。
🔄 稽古録・資源帳との連携
暦メモ（期間メモ・日メモ）は、同じサイト上の稽古録・資源帳と自動で共有されます。
一ノ倉で登録したイベントは稽古録・資源帳のカレンダーにも反映され、逆も同じです。同じ予定を何度も入力する必要はありません。
🌐 推奨ブラウザ
  • PC：Chrome / Edge / Firefox
  • スマートフォン：Chrome / Firefox / Safari
⚠ アプリ内ブラウザ（WebView）をお使いの方へ
SNS アプリなどのアプリ内ブラウザでは、Google ドライブとの同期が動作しません。
（Google のセキュリティポリシーによる制限です）
同期を使う場合は推奨ブラウザからアクセスしてください。
同期の代わりに設定の JSON インポート・エクスポートもご活用ください。
🔮断片管理タブ
宝物の断片の所持数を記録し、あと何個集めれば目標の宝物を作れるかを確認できるタブです。
表の見方
  • 必要数：その宝物を 1 つ作るのに必要な断片の数
  • 所持断片数：今持っている断片の数（ここに直接入力します）
  • 製作可能：今の断片で作れる宝物の数
  • 宝物目標数：作りたい数の目標を入力できます
  • あと必要：目標まであと何個の断片が要るか
＋ 宝物を作る
断片を消費して宝物を作り、そのまま宝物帳に登録できます。
  1. ＋ 宝物を作る を押す
  2. 宝物の種類・作る個数・最初のレベルを選ぶ（最初は通常 Lv1）
  3. 消費する断片の数が表示されるので確認して 作成する
💡 ヒント
すでに持っている宝物を断片を使わずに登録したいときは、宝物帳タブの「＋ 個体を追加」 からどうぞ。こちらは断片を消費しません。
表示の切り替え
右上のボタンでテーブル表示とカード表示を切り替えられます。スマホレイアウトのときはカード表示に固定されます。
🏆宝物帳タブ
所持している宝物を1個体ずつ管理するタブです。同じ種類の宝物を複数持っていても、それぞれ別の個体として記録できます。
個体に記録できること
  • レベル（Lv1〜5）
  • 愛用度（0〜10000）と刻名（筆頭男士の名前）
  • メモ（自由記述）
愛用度が 1000 に達するごとに「千・二千・三千…一萬」の称号がつきます。
刻名を入れて愛用度が称号に届くと、宝物名［刻名］称号 の形で正式に表示されます。
追加・編集・削除
  • ＋ 個体を追加：断片を使わずに宝物を直接登録します
  • 各カードの ⋯ メニュー から編集・習合・削除ができます
  • 削除は確認ダイアログが出るので、誤操作の心配はありません
カテゴリで絞り込む
宝物のカテゴリで表示を絞り込めます。
すべて 刀装具 武具 茶道具 馬具 絵画 彫刻
整列（並べ替え）
宝物帳順・レア度・Lv・愛用度のほか、ステータスごとに並べ替えられます。装備の検討に便利です。
打撃統率機動衝力 偵察隠蔽必殺
  • ▼ 降順 / ▲ 昇順ボタンで並び順を反転できます
  • カスタムを選ぶと、各カードの ▲▼ ボタンで好きな順に並べ替えられます
表示の切り替え
  • ⊞ グリッド：カードを並べて一覧。見た目重視
  • ≡ リスト：表形式で全ステータスを一度に確認。列の見出しを押すとその項目で並べ替え
  • 📐 高さ揃え：長い名前も省略せず全表示し、カードの高さを揃えます
⚔習合（レベル上げ）
習合は、同じ種類の宝物を素材にしてレベルを上げる機能です。宝物帳のカードの ⋯ メニュー → 習合 から行えます。
  1. レベルを上げたい宝物の ⋯ → 習合 を選ぶ
  2. 素材にする同じ種類の個体をチェックする（複数選べます）
  3. 習合後のレベルを確認して 習合する
💡 仕組み
素材1個につきレベルが1上がり、最大 Lv5 まで上がります。
素材にした個体は習合するとなくなりますのでご注意ください。
🛡️刀装タブ
刀装のステータス一覧を確認できる資料用のタブです。どの刀装を付けるか検討するときに役立ちます。
グレードの切り替え
並 上 特上
選んだグレードのステータスで一覧が表示されます。
装備できる刀種で絞り込む
短刀 脇差 打刀 太刀 大太刀 槍
並べ替え・表示
  • 兵力・打撃・統率・機動・衝力・偵察・隠蔽の各ステータスで並べ替えできます
  • ▼ 降順 / ▲ 昇順で順序を反転
  • ≡ テーブル / ▦ カードで表示を切り替え（スマホはカード固定）
🐎馬タブ
馬のステータス一覧を確認できる資料用のタブです。各ステータスで並べ替えて、付けたい馬を探せます。
  • 兵力・打撃・統率・機動・衝力・偵察・隠蔽で並べ替え
  • ▼ 降順 / ▲ 昇順で順序を反転
📅暦メモタブ
イベント期間や日々のできごとをカレンダーに記録できるタブです。記録したメモは稽古録・資源帳と共有されます。
＋ 期間メモ
イベントやキャンペーンなど、期間のある予定を登録します。開始日・終了日・色・備考を設定でき、カレンダー上に横長の帯で表示されます。
＋ 日メモ
特定の1日のできごとを記録します。目印として絵文字または色ドットを選べ、カレンダーのその日に表示されます。
メモの編集・削除
カレンダー下の「メモ一覧」から、登録済みのメモを編集・削除できます。
🔄 稽古録・資源帳と自動共有
同じサイト上に置かれた稽古録・資源帳とメモを自動で共有します。
どれか1つのアプリでイベントを登録すれば、ほかのアプリのカレンダーにも反映されます。
⚙️設定・テーマ
ヘッダー右上のボタンから設定を開けます。
テーマ（全10色）
5種類の色合い × ライト / ダークの合計10テーマから選べます。初期設定は藍蔵ライトです。
藍蔵 欅 灰瓦 朱漆 白漆喰
レイアウト切り替え（PC / スマホ）
ヘッダーのレイアウトボタンで、スマホ向けの表示に切り替えられます。PC からでもスマホでの見え方を確認できます。
クラウド同期（Google ドライブ）
Google アカウントでログインすると、データをクラウドにバックアップできます。
  • ↑ クラウドへ保存：今のデータをクラウドに書き込みます
  • ↓ クラウドから読み込む：クラウドのデータを取り込みます
保存先は Google ドライブの非表示領域で、ほかのファイルと混ざりません。
複数の端末で使うときは、新しい端末で先に ↓ 読み込み をしてください。
💾バックアップ
データはお使いの端末のブラウザにだけ保存されます。キャッシュやサイトデータを消すとデータも消えます。大切な記録は定期的にバックアップしておくと安心です。
JSON バックアップ
  • 設定 → 📤 JSON エクスポートでファイルとして保存
  • 設定 → 📥 JSON インポートで保存したファイルを読み込み
⚠ ご注意
インポートすると現在のデータが読み込んだ内容で置き換わります。
機種変更やブラウザの変更の前には、エクスポートでバックアップを取っておいてください。
❓よくある質問
Q. データが消えてしまった
ブラウザのキャッシュ・サイトデータを削除するとデータが消えます。
JSON エクスポートまたは Google ドライブ同期でバックアップを取っておいてください。
Q. 同じ宝物を2個持っている。どうやって登録する？
一ノ倉は個体ごとの管理なので、それぞれ別々に登録できます。同じ種類でもレベルや愛用度・刻名を個別に記録できます。
Q. 習合で素材にした宝物が消えた
習合では素材にした個体はなくなる仕様です。これはゲーム内の習合と同じ挙動です。間違えそうなときは、習合前に JSON エクスポートでバックアップを取っておくと安心です。
Q. スマートフォンで文字が小さい・使いにくい
ヘッダーのレイアウトボタンから スマホ表示 に切り替えると、モバイル向けの表示になります。
Q. Google ドライブにログインできない
X（Twitter）・LINE などのアプリ内ブラウザでは、Google のセキュリティポリシーにより動作しません。
Chrome・Safari・Firefox などの外部ブラウザでアクセスしてください。
Q. 暦メモが稽古録・資源帳にも出てくる
仕様です。3つのアプリでメモを共有しているため、どれか1つで登録した予定はほかのアプリにも反映されます。重複入力の手間が省けます。
Q. 刀装や馬の所持数は記録できる？
現在の刀装・馬タブはステータスを見るための資料です。所持数の管理は今後のアップデートで対応を検討しています。
